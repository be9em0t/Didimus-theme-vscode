# Changelog

All notable changes to Didimus are documented here.

## [0.1.2] - 2026-08-31

### Changed

- Tuned Didimus Deep Blue's status bar foreground to `#4f86d8` and background to `#19212C`.

## [0.1.1] - 2026-08-31

### Changed

- Refined the status bar foreground and hover styling in Didimus, Didimus Classic, and Didimus Deep Blue.
- Preserved Didimus Sundown's existing status-bar styling unchanged.

## [0.1.0] - 2026-08-30

### Added

- Added **Didimus Classic**, **Didimus Deep Blue**, and **Didimus Sundown** theme variants to the published package.
- Added the Didimus Marketplace icon and improved Marketplace metadata.

### Changed

- Theme JSON is generated from a shared source definition for repeatable releases.
- Refined editor, workbench, and token colour coverage across the included themes.
- Rewrote the README with current installation, development, and compatibility guidance.

## [0.0.4] - 2023-03-11

- Refined the published Didimus theme package.

## [0.0.3] - 2023-03-11

- Updated theme colors and token coverage.

## [0.0.2] - 2022-08-25

- Improved the theme definition for additional languages.

## [0.0.1] - 2022-08-25

- Initial release.
